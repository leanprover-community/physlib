# Configuration space

## Abstract

The manifold of configurations of a mechanical system; its charts are generalised coordinates.

## Content

A configuration space is a smooth manifold without boundary, abstracting over the mechanical
system and used across the Lagrangian API. [1]

In global generalised coordinates, a curve is smooth if and only if its coordinate curve is,
with velocity the time derivative of the coordinate curve. [planned] The configuration spaces of
the harmonic oscillator and the simple pendulum are configuration spaces. [planned]
