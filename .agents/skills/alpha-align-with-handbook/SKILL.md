Pick a single file in PhyslibAlpha which does not follow the guidance within
`./docs/ContributionHandbook`. Edit that file so that it does align with it.

## How to pick the file

This should be picked relatively at random from the worst files in PhyslibAlpha. This is to
ensure that multiple instances of this do not edit the same file in one go.
