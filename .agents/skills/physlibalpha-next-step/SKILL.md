The overall goal is to push PhyslibAlpha forward to make it the best library possible.
To do this you can choose one of a number of jobs to complete:

1. Rename a declaration to better match physics.
2. Clean up a file.
3. Add new definitions in areas which already exist.
4. Start the formalization of a new area.
5. Look at an existing API-map and determine a missing next step.

You should pick one coherent and well defined task in one of these directions, picking what
you think is most important. Though introduce some randomness into this so that it is unlikely that
you clash with other runs.

All your changes must be constrained to ./PhyslibAlpha and PhyslibAlpha.lean.
You should follow any quality standards present in Physlib.
