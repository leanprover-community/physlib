---
name: alpha-add
description: Add a given result to PhyslibAlpha whilst merging it
  with the rest of the library.
---

You will have been provided with an input `X`. This may either be
a result or another Lean formalization.

Your goal is to put `X` into PhyslibAlpha whilst:
1. Ensuring that the quality of the code meets the high standards of Physlib.
2. Ensuring that you fit it nicely with existing API within the project, and that nothing is redefined, and that the physics context is clear.

Make sure that your result aligns with `./docs/ContributionHandbook`.

Do not edit any API-map.md.
