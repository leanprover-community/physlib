# Contributing

Use [Getting Started](https://physlib.io/getting-started) to set up Lean, or
[Get Involved](https://physlib.io/get-involved) to find a contribution that
fits your background. For a Lean change, discuss a larger proposal on Zulip
and follow the [review guidelines](docs/ReviewGuidelines.md) for build, lint,
and review expectations. Follow the [GitHub guide](https://physlib.io/gh-guide)
to fork the repository and open your pull request.

## Write your first API map

Follow [the walkthrough](docs/GettingStarted/FirstAPIMap.md) to choose a topic,
draft and lint an API map locally, and submit it from your GitHub fork.
