## An AI-assisted first contribution through API-maps

[Issue #1891](https://github.com/leanprover-community/physlib/issues/1891) invites
physicists new to the project to improve API maps. Give your agent this request:

> Read `.agents/skills/physlib-alpha-api-map/SKILL.md`. I know classical mechanics
> and am new to Lean. Help me contribute to Physlib through #1891: choose a
> useful map improvement, make it, run the checks, and explain the diff for my review.

Replace classical mechanics with your interests, or supply a specific topic or map.
The [skill](.agents/skills/physlib-alpha-api-map/SKILL.md) handles the workflow; you
review the physics and references and write the PR description under [the AI policy](AI-POLICY.md).
